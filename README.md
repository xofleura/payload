Hello! This is a quick guide on how to use payload.  

Payload will be available from ./bin/payload after you make it executable

```chmod +x ./bin/payload```  

In order to create your first project, run  
```./bin/payload new example```  

Next, run the code  
```./bin/payload run```  

There are more commands, which can be seen with  
```./bin/payload help```  

This is still in early development. Don't expect something usable yet.
